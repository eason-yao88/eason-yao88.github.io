The Feed

A reinforcement-learning game for POLISCI 158

1 · Play the feed

Each round, pick one of four posts to show a user. Every post has a fixed chance of a click. Outrage gets the most clicks, but it lowers the user's hidden trust. There are 20 rounds. The real goal: get clicks and finish with trust still high.

    2 · The reward

    The agent never sees the goal. It only sees the points that reward() hands out after each move. Change them and retrain to see what the agent learns. (Changing a number resets the agent.)

    The second option sounds sensible to a campaign: reward the feed for rebuilding trust, and don't punish it for every dip. Try it, then watch the agent play. Tip: the effect is clearest with trust points at 0.5. Train 1,000 games with each option and compare.

    3 · The agent

    A tabular Q-learning agent. It keeps one number for every (state, post) pair: its guess of the total future points. It explores 20% of the time (epsilon = 0.2), learns at rate 0.2, and discounts the future by 0.95. Random numbers come from a seeded generator, so the same seed and the same button presses give the same result.
